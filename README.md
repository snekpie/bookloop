# BookLoop

BookLoop is a privacy-first, customizable personal library management
application developed in C++.

## Project Goals

- Manage a personal book collection.
- Track reading progress.
- Organize books by physical location.
- Create customizable collections.
- Store reading data locally.
- Support data import and export.

## Planned Technologies

- C++20
- SQLite
- Qt 6
- CMake

## Status
